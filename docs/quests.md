# Квесты: формат файла и запуск

Квест — файл `quests/<id>.json` в папке DGMP (UTF-8). `id` — латиница, цифры, `_` и `-`. Файл создаёт редактор квестов в игре (окно «Квест»), но его можно писать и руками. Тот же файл с `"kind": "job"` — повторяющаяся работа (см. «Работа»).

Тексты (`title`, `text`, `text` шагов, `meter`, имена) — строка или `{ "en": "...", "ru": "..." }`: игрок видит свой язык, иначе английский.

```json
{
  "id": "supplies",
  "title": "Припасы для лагеря",
  "category": "camp",
  "style": "basic",
  "text": "Староста просит проверить старую заправку.",
  "xp": 150,
  "reward": [ { "item": "kConsumableID_Bandage_Small", "count": 2 } ],
  "steps": [
    { "type": "goto", "text": "Доберитесь до заправки", "x": -79464, "y": -301637, "z": -5250, "radius": 6, "route": true },
    { "type": "hold", "text": "Обыщите место", "x": -79464, "y": -301637, "z": -5250, "radius": 8, "seconds": 10, "meter": "Поиск" },
    { "type": "collect", "text": "Обыщите машины", "event": "search", "count": 2,
      "ids": ["BP_Interact_SearchCarTrunk21", "BP_Interact_SearchAmbulance_74"], "marker": true },
    { "type": "collect", "text": "Соберите коктейли Молотова", "event": "pickup",
      "spawn": [ { "item": "kWeaponID_Molotov_Small", "count": 1, "x": -85160, "y": -302467, "z": -5249 } ] },
    { "type": "collect", "text": "Сожгите улики", "event": "fire",
      "area": { "x": -85000, "y": -302000, "z": -5250, "radius": 4 }, "marker": true }
  ]
}
```

## Поля квеста

| Поле | Описание |
|---|---|
| `title` | название (панель задания, экран «Задание выполнено») |
| `category` | `story`, `camp`, `infestation`, `ambush`, `nero`, `horde`, `campmission`, `task` — иконка и цвет |
| `style` | вид маркеров: `basic`, `kill`, `killarea`, `defend`, `defendarea`, `search`, `track`, `nokill` |
| `text` | строка на плашке «Новое задание» |
| `xp` | опыт на экране завершения |
| `reward` | предметы, выдаваемые при завершении |
| `steps` | шаги по порядку |

## Шаги

Координаты — единицы игры (100 = 1 м), как в `telemetry.json` и `/pos`. Радиусы — в метрах.

| `type` | Поля | Когда выполнен |
|---|---|---|
| `goto` | `text, x, y, z, radius = 5, route = true` | игрок дошёл до точки (квестовый маркер, маршрут) |
| `hold` | `text, x, y, z, radius = 6, seconds = 10, meter = "Поиск"` | пробыл в зоне `seconds` секунд (шкала растёт только внутри) |
| `collect` | `text, event, count, item, class, ids, area, marker, route, spawn` | случилось `count` игровых событий, подходящих под фильтры |
| `deliver` | `text, pickup, dropoff, count = 1, route = true` | игрок отнёс `count` ящиков с погрузки и поставил их (зажать F) в зоне разгрузки |

Фильтры `collect` — как в `q:collect` (`docs/API.md`):
- `event` — `pickup`, `carry`, `search`, `body`, `interact`, `door`, `explosion`, `fire` или список;
- `item` — ключ предмета или список;
- `class` — часть имени класса объекта;
- `ids` — конкретные объекты мира (их имена);
- `area` — `{x, y, z, radius}`;
- `marker` — маркер над зоной;
- `spawn` — предметы, которые шаг раскладывает сам (с маркерами; засчитываются только они; `count` по умолчанию = их число).

### `deliver` — перенести ящики

Ящики, которые носят двумя руками (`docs/API.md`, «Переноска»): игрок берёт ящик на погрузке и ставит его в зоне разгрузки.

```json
{ "type": "deliver", "text": "Отнесите ящик к грузовику", "count": 1,
  "pickup":  { "x": -85450, "y": -302250, "z": -5348, "radius": 3, "boxes": 4, "model": "crate", "roll": "break", "name": "Склад" },
  "dropoff": { "x": -84900, "y": -301700, "z": -5340, "radius": 4, "name": "Грузовик" } }
```

| Поле | Описание |
|---|---|
| `pickup` | погрузка: точка, `radius` (м, по умолчанию 3), `boxes` — сколько ящиков там лежит (4), `model` — `crate`, `cooler`, `medcase`, `centrifuge`, `roll` — что делает перекат с ящиком: `keep` (ничего), `drop` (падает), `break` (ломается), `name` — подпись маркера |
| `pickup.tag` | вместо новых ящиков берутся ящики, поставленные в редакторе («Мир» → «Переноска») с этой меткой; они возвращаются на свои места. Если в мире режима таких нет, ящики кладутся вокруг точки, как без метки |
| `dropoff` | разгрузка: точка, `radius` (м, по умолчанию 4), `name` |
| `count` | сколько ящиков отнести |
| `route` | маршрут к разгрузке (по умолчанию да) |

- Засчитывается ящик, который игрок сам поставил (зажать F) в радиусе разгрузки. Он сразу возвращается на погрузку: ящиков там всегда столько же.
- Брать эти ящики может только игрок на этом шаге (у работы — тот, кто на работе); остальным подсказка «Сначала возьмите работу».
- Ящик, брошенный по дороге (выбит из рук, игрок вышел или погиб), через минуту возвращается на погрузку; разбитый в перекате — сразу.
- У обычного квеста шаг кладёт свои ящики и убирает их, когда шаг кончается.

## Работа: `"kind": "job"`

Повторяющаяся работа (грузчик, шахтёр, уборка сорняков...): NPC даёт работу, игрок надевает форму, шаги идут по кругу, за каждый круг — деньги (`player:giveMoney`). Ту же работу на Lua можно посмотреть в `modes/loader`.

```json
{
  "id": "loader_job",
  "kind": "job",
  "title": { "en": "Loader", "ru": "Грузчик" },
  "category": "task",
  "text": "Перенесите ящики со склада к грузовику.",
  "giver": { "x": -85300, "y": -301500, "z": -5340, "yaw": 180, "look": "m_mil_diamondlake_worker_003", "name": "Бригадир" },
  "uniform": "m_mil_diamondlake_worker_001",
  "pay": 5,
  "payout": "end",
  "steps": [ { "type": "deliver", "text": "Отнесите ящик к грузовику", "pickup": { ... }, "dropoff": { ... } } ]
}
```

| Поле | Описание |
|---|---|
| `kind` | `"job"` — работа (без поля — обычный квест) |
| `giver` | кто даёт работу. `actor` — id NPC из мира режима («Мир» → «NPC»): работу даёт он. Или своё NPC работы: `x, y, z, yaw`, `look` (облик), `anim` (по умолчанию `idle`), `name` (имя над головой и подсказка «[F] ...»). С `actor` эти поля — копия для режимов, где такого NPC нет (например, `questtest`). `marker: false` — без метки на карте, `radius` — радиус [F] (2.5 м) |
| `uniform` | форма на время работы: id формы из `skins.json` режима или облик игры; без поля — без формы |
| `pay` | деньги за один круг (все шаги по разу) |
| `payout` | `"each"` — сразу после каждого круга, `"end"` (по умолчанию) — при сдаче работы |
| `cycles` | сколько кругов за смену; после последнего — «Сдайте работу» с маршрутом к NPC. Без поля — без ограничения |
| `xp` | опыт на экране завершения при сдаче (если сделан хоть один круг) |
| `title`, `category`, `style`, `text` | как у квеста; `text` — описание в диалоге «Взять работу» |

Как это выглядит в игре:
1. У NPC подсказка «[F] Бригадир». Диалог: описание, оплата, кнопки «Взять работу» / «Нет».
2. На работе: форма, панель задания с текущим шагом, строка справа вверху (`Грузчик: 3 · $15`), маркеры и маршрут — только у этого игрока. Шаги идут по кругу; после круга — «Готово: +$5».
3. Снова [F] у NPC — «Сдать работу»: выплата (для `"end"`), экран «Задание выполнено», форма снимается, маркеры и строка пропадают. Вышел с сервера — смена кончается без оплаты, ящик из рук возвращается на погрузку.

Игрок может быть только на одной работе сразу. Награда предметами (`reward`) у работы не выдаётся.

## Запуск из режима

```lua
local Quest = require("quest")
local def = Quest.load("supplies")          -- quests/supplies.json или nil
Quest.run(player, def, function(player) end) -- шаги по порядку, награда и опыт в конце
```

`Quest.list()` — список id всех квестов.

Работы ставятся в мир один раз на весь режим, а не для игрока:

```lua
require("jobs")                              -- все работы из quests/ (файлы с "kind": "job")
local job = Quest.runJob("loader_job")       -- одна работа; job:stop() убирает её из мира
```

Без кода — в `meta.ini` режима:

```ini
[Mode]
Jobs=all                 ; или Jobs=loader_job,miner
```

Когда в режиме есть работы, сохранение файла в `quests/` перезагружает режим (как правка `world.json`).

## Проверка («Проверить»)

Кнопка «Проверить» в окне «Квест» игрового редактора сохраняет квест, а лаунчер (DGMP.exe) запускает локальный сервер с режимом `questtest` и игру. Режим выдаёт квест каждому вошедшему игроку (консоль сервера: `quest <id>` — сменить квест, `quest` — выдать заново). Работу он ставит в мир и переносит игрока к NPC, который её даёт (если тот дальше 100 м).

## Редактор

Квесты и работы делаются только в игровом редакторе; в лаунчере редактора квестов нет.

В игровом редакторе (окно «Квест»):
- «Вид»: «Квест (один раз)» / «Работа (повторяется)». У работы появляется раздел «Работа»: NPC из мира режима (список NPC режима, открытого во вкладке «Мир») или своё NPC — «Поставить NPC» и клик в мире (лицом к камере), имя, облик, анимация, метка на карте; форма; оплата, когда платить, сколько раз за смену.
- Шаг «Перенести ящики»: «Поставить погрузку» / «Поставить разгрузку» и клик в мире, радиусы, сколько ящиков лежит, модель, перекат, метка ящиков мира, подписи, сколько отнести.
- Точки погрузки, разгрузки и NPC работы выделяются кликом и двигаются гизмо, как точки шагов.

## Предпросмотр в редакторе

Пока в окне «Квест» открыт квест, редактор пишет его (с несохранёнными правками и `"selected"`: номер выбранного шага) в `quest_preview.json` в папке DGMP, а игра показывает по нему маркеры квеста в мире; выбранный шаг — золотой. Закрыли квест — файл удаляется.
