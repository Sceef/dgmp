# Клиентские скрипты (клиентский Lua)

Часть режима, которая работает **в игре у каждого игрока**, а не на сервере. Как client scripts в FiveM или клиентская сторона MTA. Сервер раздаёт файлы, а игра выполняет их в песочнице.

Зачем: всё, что должно отзываться **мгновенно**, без поездки до сервера и обратно:
- свой HUD, который рисуется каждый кадр (спидометр, компас, метки над игроками, прицел);
- клавиши (нажал — сразу результат);
- локальные команды чата (`/fps`, `/hud`);
- лучи из камеры («на кого я смотрю»);
- мини-игры и логика HTML-интерфейса без сервера.

Сервер по-прежнему решает всё важное: деньги, предметы, урон. Клиентский скрипт только показывает и просит.

Пример — режим [`clientdemo`](../modes/clientdemo): `dgmp-server.exe --mode clientdemo`.
- Спидометр и компас поверх игры.
- Имя игрока под прицелом; G — помахать ему (запрос на сервер, сервер проверяет расстояние).
- `/fps` и `/ping` — локальные команды.

## Файлы

`modes/<режим>/client/` (можно с подпапками):
- что скачивается: `.lua`, `.json`, `.txt`, до 1 МБ на файл;
- точка входа — `client/main.lua`;
- `require("hud")` загружает `client/hud.lua`, `require("ui.speedo")` — `client/ui/speedo.lua`; каждый модуль выполняется один раз.

Как это работает:
- **Раздача.** Игра скачивает файлы при входе и кэширует их по содержимому (`cache/scripts/<sha256>`), как картинки и HTML-интерфейс режима.
- **Горячая перезагрузка.** Когда файл режима меняется на диске, сервер перезагружает режим. Скрипты у игроков останавливаются и запускаются заново, а докачивается только изменённое.
- **Ошибки.** Ошибка скрипта пишется:
  - в лог игры `logs/DGMP.log` — со стеком вызовов;
  - один раз в чат игрока (красная строка `[client] ...`);
  - в консоль сервера: `[режим] client script error (Ник): ...`.

## Связь с сервером

Клиент:
```lua
send("buy", { item = "kAmmoID_Pistol", count = 2 })   -- на сервер; true, если ушло (не больше 60 в секунду)
onServer("price", function(data) ... end)            -- player:clientSend("price", data) на сервере
```

Сервер (`main.lua`):
```lua
on("clientMessage", function(player, name, data)
    if name == "buy" then ... end                    -- проверяйте data: игрок может прислать что угодно
end)
player:clientSend("price", { item = "...", cost = 120 })
```

Правила:
- **Сообщения** — любые значения JSON. Имя — до 64 символов; данные: клиенту — до 64 КБ, серверу — до 16 КБ. Сервер принимает от игрока не больше 60 сообщений в секунду.
- **Порядок.** Сообщения сервера, пришедшие до запуска скриптов, дождутся его.

## События и таймеры

| Функция | Что делает |
|---|---|
| `on("frame", fn(dt))` | каждый кадр (`dt` — секунды с прошлого кадра). Здесь рисуют |
| `on("stop", fn())` | скрипты останавливаются: режим перезагружен или игрок отключился |
| `bindKey("G", fn(key) [, {block = true}])` / `unbindKey("G")` | нажатие клавиши, пока игрок играет: не в чате, не в диалоге, не в меню, не мёртв, страница режима без фокуса. `block = true` — игра это нажатие не получает (в чате и диалогах клавиша работает как обычно; кнопки мыши не забираются) |
| `isKeyDown("SHIFT")` | клавиша зажата сейчас (когда окно игры активно) |
| `command("fps", fn(args, ...))` | команда чата `/fps`: выполняется на месте, на сервер не уходит. Слова передаются после строки `args`, как на сервере |
| `after(ms, fn)` / `every(ms, fn)` → id; `cancelTimer(id)` | таймеры |
| `now()` | секунды (монотонные часы) |

**Клавиши:**
- `A`–`Z`, `0`–`9`, `F1`–`F12`;
- `SPACE ENTER TAB SHIFT CTRL ALT BACKSPACE`;
- `UP DOWN LEFT RIGHT INSERT DELETE HOME END PAGEUP PAGEDOWN`;
- `MOUSE1`–`MOUSE5`, `NUM0`–`NUM9`.

Без `block` игра тоже получает нажатие: выбирайте клавиши, которые она не использует (B, например, — бинокль), или забирайте их у игры.

## Что скрипт знает

| Функция | Ответ |
|---|---|
| `me()` | `{id, name, x, y, z, yaw, speed, health, dead, onBike, world, lang}`. `speed` — единиц (см) в секунду, `health` — проценты, `lang` — `"ru"` / `"en"` |
| `players()` | другие игроки, которых видно в этой игре (тот же виртуальный мир, не наблюдатели): `{{id, name, x, y, z, yaw, health, onBike, dead}, ...}` |
| `camera()` | `{x, y, z, pitch, yaw, fx, fy, fz}`, где `fx, fy, fz` — направление взгляда длиной 1 |
| `screen()` | `w, h`: размер кадра в пикселях |
| `worldToScreen(x, y, z)` | `sx, sy` в пикселях или `nil`, если точка позади камеры |
| `raycast(x1, y1, z1, x2, y2, z2)` | первое препятствие на отрезке: `{x, y, z, distance, class, player}` или `nil`. Тела других игроков проверяются как капсулы: при попадании `player` = их id, `class = "player"` |

Координаты — те же единицы, что на сервере: 1 = 1 см.

Луч из прицела:
```lua
local c = camera()
local hit = raycast(c.x, c.y, c.z, c.x + c.fx * 3000, c.y + c.fy * 3000, c.z + c.fz * 3000)  -- 30 м
if hit and hit.player then ... end
```

## Рисование — `draw.*`

Вызывайте в `on("frame")`. Нарисованное показывается в этом кадре и исчезает в следующем: каждый кадр рисуют заново (immediate mode). В меню, на карте и на загрузке рисунки скрыты. Координаты — пиксели от левого верхнего угла (`screen()` даёт размер).

```lua
draw.text(x, y, "текст", { size = 16, color = "#FFE08A", align = "left|center|right", shadow = true })
draw.text3d(x, y, z, "над точкой мира", { distance = 5000 })   -- по центру над точкой; true, если видна
draw.rect(x, y, w, h, "#00000088", { fill = true, rounding = 6, thickness = 1 })
draw.line(x1, y1, x2, y2, "#FFFFFF", 2)
draw.circle(x, y, radius, "#FF0000", { fill = false, thickness = 2 })
draw.image("logo.png", x, y, w, h)   -- картинка из modes/<режим>/images
```

**Цвета.** Строкой `"#RRGGBB"` или `"#RRGGBBAA"` (с прозрачностью). Числом `0xRRGGBB`, или `0xRRGGBBAA`, если число больше `0xFFFFFF`. Чёрный с прозрачностью числом не записать (`0x00000088` прочитается как синий `0x000088`) — пишите строкой.

Ограничение — 5000 фигур за кадр. Кириллица в тексте поддерживается.

## Действия у себя

| Функция | Что делает |
|---|---|
| `chat(text [, color])` | строка в чате только у этого игрока |
| `hint(title, text [, seconds])` | подсказка игры (как `player:hint`) |
| `playSound(name, {x=, y=, z=, volume=1, pitch=1})` | звук только у себя. Имя из `data/sounds.txt` или путь `/Game/...`; без `x, y, z` — без позиции |
| `uiSend(name, data)` | сообщение HTML-странице режима: `dgmp.on(name, fn)` |
| `onUi(name, fn(data))` | сообщение страницы `dgmp.send(name, data)` получает клиентский скрипт, а не сервер |

С `onUi` логика интерфейса может жить в игре. Страница шлёт `dgmp.send("tab", "map")`, а клиентский скрипт отвечает ей сам: без сервера, без задержки. Сообщения без своего `onUi` по-прежнему уходят на сервер (`on("uiMessage")`).

### Свои объекты и значки

Только у этого игрока (другие их не видят): предпросмотр мебели перед покупкой, метки «мои цели», подсветка
места. Общие для всех объекты и значки по-прежнему создаёт сервер (`createObject`, `createBlip` в `main.lua`).

| Функция | |
|---|---|
| `createObject{model= или asset=, x, y, z, pitch, yaw, roll, scale = 1, collision = true, ghost = false}` → id | `model` — меш из `data/props.txt`, `asset` — путь `/Game/...`; до 500. `ghost = true` — «призрак»: обводка игры (как у чутья выживания) и мерцание, без столкновений — предпросмотр «сюда встанет» |
| `setObject(id, {поля})` | сразу на месте (движение прекращается) |
| `moveObject(id, {x, y, z, pitch, yaw, roll, time = секунды или speed = м/с})` → секунды | плавно туда |
| `removeObject(id)` | |
| `createBlip{x, y, z, icon = "MAP_...", color, scale = 1, map = true, radar = true, edge = false}` → id | значок на карте и радаре, до 200 |
| `setBlip(id, {поля})`, `removeBlip(id)` | |

Когда скрипты останавливаются, их объекты и значки исчезают.

### Хранилище — `storage.*`

Данные скриптов на компьютере игрока, отдельно для каждого сервера и режима (`cache/scriptdata/`): настройки
интерфейса, положение окон, «уже показывали подсказку». До 256 КБ. Сохраняется само (раз в 5 с и при остановке).

```lua
local runs = (storage.get("runs") or 0) + 1
storage.set("runs", runs)        -- любые значения JSON; nil удаляет
for _, key in ipairs(storage.keys()) do print(key) end
```

Это не место для денег и предметов: игрок может переписать файл. Важное храните на сервере (`storage` в `main.lua`).

Ещё есть: `json.encode` / `json.decode`, `print` / `log` (в `logs/DGMP.log` со строкой `[client]`), стандартные `string`, `table`, `math`, `utf8`, `coroutine`, `os.time` / `os.clock` / `os.date`.

## Песочница и ограничения

Код с сервера выполняется на компьютере игрока, поэтому:
- **Нет доступа к системе:** нет `io`, `os.execute` / `getenv` / `remove`, `package`, `debug`, `dofile` / `loadfile`.
- **Нет байткода:** `load` принимает только текст, `string.dump` убран.
- **Время.** Один вызов — кадр, клавиша, сообщение, таймер — работает не дольше 100 мс; первый запуск `main.lua` — до 2 с. Дольше — ошибка «ran longer than…». Обработчик `on(...)` или повторяющийся таймер, который превысил время, отключается: каждый кадр снова он бы замораживал игру.
- **Память.** До 64 МБ на все скрипты режима.
- **Клиенту нельзя доверять.** Игрок может изменить свою игру и прислать что угодно. Всё, что даёт выгоду (деньги, предметы, урон, телепорт), сервер проверяет сам: расстояния, цены, права. Клиентский скрипт только показывает и просит.

## Чего пока нет

- **NPC и маркеров заданий только у одного игрока.** Их создаёт сервер (`createActor`, `createMarker`).
- **Блокировки движения и камеры** (только отдельных клавиш, `bindKey(..., {block = true})`).
