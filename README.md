# DGMP — мультиплеер для Days Gone

- **`DGMP.exe`** — лаунчер: ник, серверы (избранное, недавние, локальная сеть, подключение по IP), создание сервера с выбором режима и живой консолью, вход в редактор.
- **`dgmp-server.exe`** — выделенный сервер (UDP, порт 7777). Работает без игры, в том числе на VPS. Настройки — `server.ini`. Есть сборка для Linux (`dgmp-server`, CMake): [`docs/server-linux.md`](docs/server-linux.md) — сборка, запуск, systemd, файрвол.
- **Режимы** — Lua-скрипты в `modes/<id>/`. Документация для разработчиков: [`docs/API.md`](docs/API.md), ключи предметов: [`docs/items.md`](docs/items.md). Примеры: `modes/freeroam` (основа), `modes/race` (гонки), `modes/loader` (работа грузчиком: переноска ящиков, оплата деньгами) — полный список в начале `docs/API.md`.
- **Клиент** — `version.dll` в изолированной копии игры. Показывает других игроков (тело с позой костей, мотоцикл, ник над головой в мире, метка на карте), чат на T, подсказки сервера родными окнами игры.
- **Сборка** — `build.bat` (MSVC 2022): DLL, сервер, лаунчер, тестовый клиент `build/dgmp-probe.exe`.
- **Отладка** — если существует папка `dev/`, DLL принимает команды исследования через `tools/dev.sh` (поиск объектов, свойства, вызов функций).

Ниже — описание редактора (режим «Редактор» в лаунчере).

## Редактор

Запуск: `DGMP.exe --editor` или кнопка «Редактор» в лаунчере. Steam должен работать, Days Gone перед запуском нужно закрыть.

Лаунчер готовит отдельную копию EXE в `runtime/BendGame/Binaries/Win64`. Контент и Engine подключены через directory junction. DLL коопа, его конфигурация и исходные игровые бинарники не изменяются. Не удаляйте общий контент через ссылки внутри `runtime`.

Профиль игры перенаправлен в `profiles/editor/BendGame/Saved`. Мир берётся из общего шаблона `worlds/bootstrap/world.sav`; основа — предоставленный автором слот 2 после пролога, на стандартной сложности и без прокачки. Общий `profile.sav` входит в шаблон, поэтому старый личный профиль также не подмешивается. При каждом запуске восстанавливаются два канонических файла: стартовый `slot01.sav` и `profile.sav`. Подготовка сверяет их размер и SHA-256 с `manifest.json`.

Лаунчер определяет папку текущего аккаунта через Steam и устанавливает туда файлы шаблона, включая первую установку без локальных сюжетных сохранений. Автосейвы, checkpoints и инвентарь пользователя не импортируются. Предыдущий профиль DGMP при смене шаблона сохраняется в `profiles/backups`. Графические настройки `.ini` текущего профиля сохраняются; оригинальные игровые сейвы подготовка не изменяет.

Прототип автоматически загружает слот и включает полёт. Загрузочная заглушка закрывает клиент игры до готовности мира и точного перемещения на сохранённый спавн; снизу отображаются этапы и прогресс перехода. Шкала показывает этапы, а не процент прочитанных файлов. Используется штатный `BendGame/Content/Splash/Splash.bmp`; собственную картинку можно положить в `assets/loading.png`. При сворачивании или переключении на другое приложение заглушка скрывается вместе с игрой. Курсор заглушки — обычная стрелка.

Основа мира теперь повторяема и не зависит от личного прогресса установившего DGMP игрока. Шаблон остаётся валидным сюжетным сейвом: подавление заданий, раскрытие карты и снятие исследованных ограничений выполняются при инициализации мода. Загрузка общего шаблона проверена в игре; автоматический вход и выравнивание спавна проходят. Перенос между разными Steam-аккаунтами ещё требует проверки. Выделенный сервер, сохранение прогресса сервером и полностью независимый спавн персонажа ещё не реализованы.

Штатные задания приостанавливаются через менеджер заданий, отслеживание снимается также с сюжетных триггеров. Отключены их указатели, маршрут задания, сведения о гнёздах и сюжетная озвучка. Красная заливка заражения убирается из материала карты; отдельные объекты гнёзд отключаются в мире без удаления зданий. Открываются исследованные spline-блокеры проходов и снимаются штатные флаги блокировки дверей. Это не доказывает отсутствие всех сюжетных вариантов геометрии во всех локациях.

В DGMP отключён штатный фоторежим. Из игрового меню доступна карта: переходы в навыки, предметы, сюжет и модификаторы отключены, соответствующие кнопки и сюжетные панели карты скрыты. Карта показывает все три региона без тумана войны; её маска раскрытия переопределяется только при отображении, данные исследования сюжетного сохранения не заполняются.

Полное раскрытие включено по умолчанию: `[World] RevealMap=1` в `DGMP.ini`. Значение `0` при следующем запуске оставляет штатный туман и доступность регионов из загрузочного сохранения. API для тумана отдельных участков и ограничений пользовательских режимов ещё предстоит добавить. Раскрытие карты не означает, что устранены все сюжетные зависимости физических локаций.

## Управление

| Клавиша | Действие |
|---|---|
| F2 | Полёт включить / выключить; штатный фоторежим отключён |
| F3 | Открыть / закрыть дев-меню |
| ЛКМ / ПКМ в полёте | Зарезервированы для инструментов редактора |
| WASD | Двигаться по направлению камеры |
| Пробел / Ctrl | Вверх / вниз |
| Shift | Скорость ×4 |
| [ / ] | Уменьшить / увеличить скорость |
| F5 | Сохранить позицию как точку старта |
| F6 | Записать маркер карты |
| F8 | Вернуться на сохранённый старт |

Координаты указаны в единицах Unreal: 100 единиц = 1 метр. Перед отключением полёта опуститесь на поверхность. Панель координат — внешнее прозрачное окно; для её отображения используйте оконный режим или без рамки.

Инструменты размещения объектов пока не реализованы: нажатия мыши в полёте фиксируются в логе и телеметрии. При открытой карте её управление мышью сохраняется, движение полёта приостанавливается. После выключения полёта обычные боевые действия возвращаются.

В полёте штатные боевые действия, чутьё, перекат, колесо оружия, лечение и взаимодействия блокируются. Пробел используется для подъёма; мышь вращает камеру.

## Метки и ранний API

По умолчанию включены игрок, мотоцикл, топливо и пользовательская метка. Настройки `[Map]`: `Player`, `Motorcycle`, `Fuel`, `UserWaypoint`, `OtherNativeMarkers`. Пользовательская метка и её маршрут сохраняются отдельно от сюжетного указателя.

Заголовок `api/dgmp.h` описывает экспортируемые функции `DGMP_SetMapCategoryVisible(category, visible)` и `DGMP_GetMapMarkerMask()`. Их нужно получать из DLL DGMP через `GetProcAddress`. Изменения применяются в игровом потоке. Это локальное управление штатными категориями, а не готовый серверный SDK или API создания собственных заданий. В режиме подавления сюжета категория waypoint сохраняет только пользовательскую метку; штатные сюжетные акторы остаются отключены.

## Дев-меню и окружение

F3 открывает дев-меню после готовности мира, при закрытой карте и меню паузы. Управление: ↑/↓ выбирают строку, ←/→ меняют значение, Enter переключает настройку; в строке времени Enter ставит полдень. Время меняется с шагом 15 минут. Кнопки −/+ работают мышью, F3 или Esc закрывают меню. Пока меню открыто, управление персонажем, камера и перемещение полёта приостановлены.

Доступны время суток, остановка часов, выбор штатного погодного пресета, автоматическая смена погоды и категории игрока, мотоцикла, топлива и пользовательской метки. Погодные пресеты берутся из `EWeatherType` установленной игры. Ручной выбор погоды выключает её случайную смену; переключатель возвращает штатную автосмену. Переход между пресетами выполняет движок.

API в `api/dgmp.h`: `DGMP_SetTimeOfDay(hours)`, `DGMP_SetTimePaused(0/1)`, `DGMP_SetWeather(id)`, `DGMP_SetWeatherAutomatic(0/1)`, `DGMP_GetEnvironmentState`, `DGMP_GetWeatherCount`, `DGMP_GetWeatherInfo`, `DGMP_SetDevMenuVisible` и `DGMP_IsDevMenuVisible`. Время задаётся в часах [0,24): 18.5 означает 18:30. Список ID погоды нужно получить из каталога API; номер строки каталога и ID могут отличаться.

Сеттеры ставят команду в очередь, возвращая 1 при принятии и 0 при неверном аргументе или заполнении очереди. Unreal изменяется в игровом потоке после готовности мира. Читающие функции возвращают копию состояния; перед вызовом нужно заполнить `structSize`. `requestedRevision`, `processedRevision`, `lastRequestResult` позволяют отличить принятую команду от применённой. Пример: `api/environment_example.cpp`. Настройки окружения пока действуют локально в текущей сессии; сетевую репликацию и серверные права доступа ещё предстоит добавить.

Для диагностики в `control.ini` добавлены команды `dev_menu` (`Visible`), `set_time` (`Hours`), `time_paused` (`Paused`), `set_weather` (`WeatherId`) и `weather_automatic` (`Enabled`). Для каждой команды нужно увеличивать `Sequence`. Телеметрия содержит текущее время, каталог и выбранный ID погоды, состояние автосмены и номера обработанных запросов.

Дев-меню и API v0.5 собраны; проверка их поведения в игре отложена по просьбе пользователя.

## Сохранения

В v0.4.2 добавлены запрет штатного сохранения в GameMode, снятие запроса автосейва, блокировка быстрого и ручного сохранения, скрытие подсказок и отключение пункта сохранения. Дополнительно файловые перехваты запрещают создавать, перезаписывать, удалять и заменять сейвы в игровом профиле DGMP, включая временные файлы в `SaveGames`. Чтение загрузочного слота разрешено; лаунчер может восстановить стартовый файл перед запуском.

Настройки игры в `.ini`, файлы редактора `DGMP.ini` и `maps/markers.jsonl` сохраняются. Для прогресса режима предстоит реализовать отдельное серверное хранилище. Новая блокировка сохранений собрана, но её проверка в игре отложена по просьбе пользователя. Оригинальная игра использует свои бинарники и сохраняется обычным способом.

Старт хранится в секции `[Spawn]` файла `DGMP.ini`; при следующем запуске применяется после загрузки мира. Чтобы вернуться к исходной позиции, установите `Enabled=0`. Маркеры записываются в `maps/markers.jsonl`.

## Диагностика и сборка

- `logs/DGMP.log` — модуль и автоматическая загрузка.
- `logs/launcher.log` — запуск.
- `telemetry.json` — состояние мира и координаты, обновляемые раз в секунду.
- `build.bat` — сборка MSVC 2022 x64.
- `CMakeLists.txt` — сборка только сервера под Linux: `cmake -S . -B build-linux && cmake --build build-linux -j` (подробно в [`docs/server-linux.md`](docs/server-linux.md)).
- `prepare.ps1` — подготовка без запуска, восстановление общего шаблона. Выполнять при закрытой игре; `-RefreshSeed` сохранён для совместимости и также восстанавливает общий шаблон.
- `DGMP.exe --prepare-only` — только подготовка.
- `DGMP.exe --editor --refresh-seed` — восстановить общий шаблон и запустить редактор; личные сейвы не импортируются.

Используется тот же исследованный доступ к UE 4.11 Bend fork, что в DGCoop, но с отдельной копией исходников. Поддерживается только EXE с TimeDateStamp 1752517958. Steam API коопа и его сетевой код здесь не используются.

В меню паузы DGMP удаляются пункты «Сохранить», «Загрузить», «Фоторежим» и «Главное меню». Пункты и их кнопки удаляются согласованно, индексы выбора пересчитываются. Настройки, справка и выход в систему сохраняются. Если структура меню не совпадает с проверенной, указанные пункты отключаются и скрываются; их штатные обработчики также блокируются.
