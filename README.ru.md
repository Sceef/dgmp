# DGMP — мультиплеер для Days Gone

DGMP — мод, который добавляет в Days Gone мультиплеер с выделенным сервером и игровыми режимами на Lua (по образцу SA-MP, MTA и FiveM).

Состав проекта:

- **`DGMP.exe`** — лаунчер. В нём задаётся ник, есть список серверов (избранное, недавние, локальная сеть, «Интернет», подключение по IP), создание своего сервера с живой консолью, вход в редактор и обновления.
- **`dgmp-server.exe`** — выделенный сервер (UDP, порт 7777). Игра для него не нужна. Сервер работает на Windows и Linux, в том числе на VPS.
- **Клиент** — `version.dll`. Лаунчер кладёт его в отдельную копию EXE игры, поэтому оригинальная игра и её сохранения не меняются.
- **Режимы** — Lua-скрипты в `modes/<id>/`. Каждый режим выполняется на сервере, а при желании и у игроков (клиентские скрипты, HTML-интерфейс).
- **Редактор** — внутриигровой редактор мира режима: пропсы, свет, NPC, транспорт, двери, лут, точки логики, скины, квесты.

## Скачать и играть

1. Скачайте `DGMP-client-<версия>.zip` из [Releases](https://github.com/Sceef/dgmp/releases/latest).
2. Распакуйте папку `dgmp` в корень установленной Days Gone, рядом с `BendGame` (не в `Binaries/Win64`):
   ```
   Days Gone/
     BendGame/
     Engine/
     dgmp/DGMP.exe
   ```
3. Запустите Steam, закройте Days Gone, если она открыта, и запустите `dgmp/DGMP.exe`. Введите ник и подключитесь к серверу.

Лаунчер обновляется сам: когда выходит новая версия, в нём появляется кнопка «обновить» — она скачивает релиз, проверяет и ставит его, сохраняя ваши настройки.

## Публичный тестовый сервер

**Рубеж | DGMP RP** — `179.66.187.53:7777` (режим `outpost`, RP-лагерь). В новой установке лаунчера он уже есть в «Избранном». Подключиться можно только клиентом той же версии протокола: DGMP 0.8.x (протокол 11).

## Что нового в 0.8

Версия протокола 11: клиенты и серверы 0.7 с 0.8 не совместимы.

- **Меню игрока.** Посмотрите на игрока рядом и нажмите **F**: режим показывает свои действия (в Рубеже — отряд, обмен, частота рации, деньги, помощь медика, документы, обыск, «связать», дуэль). Если нужно согласие второго игрока, у него внизу экрана появляется вопрос с ответом **Y** / **N**, игра при этом не останавливается. Библиотеки `interact`, `squad`, `trade`, `medic`, `instance` лежат в `modes/_lib/`.
- **Наведение.** Когда рядом несколько NPC, дверей, ящиков или игроков, подсказка «[F] …» достаётся тому, на кого смотрит камера и кто не за стеной.
- **Ранение вместо смерти** (`setDeathMode("downed")`). Игрок падает, когда полоска здоровья пуста, и лежит, пока не истечёт кровью: позвать помощь — **H**, сдаться — удерживать **E**, медик поднимает его из меню игрока.
- **Дуэли и арены** (`instance`). Бой идёт в своём виртуальном мире со своим оружием. После боя возвращаются место, рюкзак и здоровье, ничего не тратится.
- **Tab — список игроков.** В нём пинг, кто говорит, свои столбцы режима, «Заглушить» и громкость каждого игрока (только у себя; заглушённый голос сервер больше не присылает) и кнопка настроек голоса. Голос на сервере можно включать и выключать на лету (`voice on|off`, `setVoiceEnabled`).
- **Меню карты (Esc).** В углу вместо «дней прожито» показаны число игроков, название сервера и режим. Значок другого игрока на карте при наведении показывает его ник.
- **Чат** понимает цветовые коды `{RRGGBB}`, как диалоги и HUD.
- **Лаунчер** показывает версию каждого сервера (красным, если протокол другой) и сам обновляется из GitHub Releases ([`docs/releases.md`](docs/releases.ru.md)).
- **Рубеж:** поиск деталей и экспедиция NERO идут на местах заданий со своим слоем для каждого игрока или отряда; медикаменты NERO — квестовый предмет для медпункта; обучение ведёт от первой доставки до экспедиции.
- **API:** `player:ask`, `setPlayerMenu` / `playerInteract`, `player:setControls`, `createBlip({follow = player})`, `setScoreboard`, события `playerDowned`, `playerBleedout`, `playerHelp`, `voiceIgnore`. Всё описано в [`docs/API.md`](docs/API.ru.md), что проверено — в [`VERIFICATION.md`](VERIFICATION.md).

## Требования

- Days Gone из Steam (поддерживается только сборка EXE с TimeDateStamp `1752517958`) и запущенный Steam.
- Windows 10 1903+ x64, WebView2 Runtime (обычно уже установлен вместе с Edge).
- Для сборки: Visual Studio 2022 (Community подойдёт) с компонентом «Разработка классических приложений на C++».
- Для сервера на Linux: g++ 10+ или clang 12+ и CMake 3.16+.

## Сборка из исходников

Папка `dgmp/` должна лежать в корне игры, рядом с `BendGame/`:

```
Days Gone/
  BendGame/
  Engine/
  dgmp/        ← этот репозиторий
```

Сборка всего сразу (DLL клиента, сервер, лаунчер, тестовый клиент):

```bat
build.bat
```

Скрипт сам вызывает `vcvars64.bat` из стандартного пути VS 2022 Community. Если у вас другая редакция или путь, поправьте первую строку `build.bat`. Сторонние библиотеки (Lua, ENet, Dear ImGui, ImGuizmo) лежат в `third_party/` и собираются один раз в `build/*.lib`. Чтобы пересобрать их заново, удалите соответствующий `.lib`.

Результат:

| Файл | Что это |
|---|---|
| `DGMP.exe` | лаунчер |
| `dgmp-server.exe` | выделенный сервер (+ `.pdb` для стеков при падениях) |
| `build/version.dll` | клиент; лаунчер копирует его в `runtime/` при запуске |
| `build/dgmp-probe.exe` | тестовый клиент без игры |

`python tools/package-client.py` собирает ZIP клиента, `python tools/release.py` выпускает релиз ([`docs/releases.md`](docs/releases.ru.md)).

## Запуск игры

1. Запустите Steam и закройте Days Gone, если игра открыта.
2. Откройте `DGMP.exe`, введите ник и подключитесь к серверу из списка или по IP.

При первом запуске лаунчер собирает отдельную копию игры в `runtime/`. Контент туда не копируется, он подключается ссылками (directory junction). Отдельный профиль создаётся в `profiles/`. Мир загружается из общего стартового сохранения `worlds/bootstrap/`, поэтому личный прогресс игрока не используется и не изменяется. Не удаляйте файлы игры через ссылки внутри `runtime/`.

Ключи лаунчера:

- `DGMP.exe --editor` — сразу открыть редактор.
- `DGMP.exe --prepare-only` — только подготовить `runtime/` и профиль, без запуска.
- `DGMP.exe --refresh-seed` — восстановить стартовое сохранение из шаблона.

В игре чат открывается на **T**, голосовой чат работает на **N** (рация — **K**). Клавиши и громкость настраиваются в `DGMP.ini`, секция `[Voice]`, или командой `/voice`. **Tab** — список игроков сервера: пинг, кто говорит, «Заглушить» и громкость каждого (только у себя), настройки голоса. **F** на другом игроке открывает меню игрока режима (если режим его дал), на вопросы режима отвечают **Y** / **N**.

### Редактор: сохранения и диагностика

В окне редактора выбирается автосохранение: выключено, раз в **1, 5 или 10 минут** (по умолчанию — 1 минута). Сохраняются изменённые мир, скины и открытый квест. Файлы заменяются атомарно; предыдущая версия остаётся в `.bak`, копия для восстановления — в `.autosave/` рядом с документом. При изменении файла другой программой автосохранение оставляет основной файл нетронутым и пишет копию для восстановления. Статус виден в редакторе. Для восстановления закройте редактор, сохраните копию текущего файла и скопируйте нужную версию из `.autosave/` или `.bak` на его место.

**M** открывает игровую карту. Двойной щелчок левой кнопкой задаёт точку телепорта редактора; **M/Esc** закрывает карту. После загрузки местности камера остаётся в полёте над поверхностью.

«Диагностика разработки» включает дополнительные события, состояние памяти и дампы исключений в `logs/diagnostics/<сеанс>/`. Она включена по умолчанию в редакторе; настройка сохраняется в `editor.ini`. Сеанс хранит точную DLL и соответствующие символы сборки. Дамп помечен `FIRST-CHANCE`: исключение может быть обработано игрой и само по себе ещё не доказывает падение. Число дампов ограничено восемью разными адресами за сеанс. Для записи нужен `build/dgmp-crashdump.exe`, собираемый вместе с клиентом. Диагностика ничего не отправляет в сеть.

Проверки хранения и сборщика дампов: `tests\editor-tools.bat` из среды Visual Studio x64. Результаты остаются в отдельных тестовых каталогах `build/`; файлы режима не используются.

## Свой сервер

### Быстро, из лаунчера

«Создать сервер» → выберите режим. Лаунчер запустит `dgmp-server.exe` и покажет его консоль. Игрок с того же компьютера (127.0.0.1) по умолчанию становится админом (`LocalAdmin=1`).

### Выделенный сервер на Windows

```bat
dgmp-server.exe --mode freeroam --port 7777
dgmp-server.exe --config my.ini --name "Мой сервер" --max 32 --password secret --bind 0.0.0.0
```

Флаги командной строки (`--name --mode --port --max --password --bind --master-server --config`) перекрывают значения из `server.ini`. Откройте в файрволе и на роутере **UDP 7777**. TCP не нужен: этот же порт отвечает на запросы статуса из лаунчера.

### Сервер на Linux / VPS

Сборка через CMake, юнит systemd, файрвол и разбор падений описаны в [`docs/server-linux.md`](docs/server-linux.ru.md). Коротко:

```bash
cmake -S . -B build-linux && cmake --build build-linux -j
./dgmp-server --mode freeroam
```

### `server.ini`

Все ключи описаны комментариями в самом [`server.ini`](server.ini). Основные:

| Ключ | Назначение |
|---|---|
| `Name`, `Mode`, `Port`, `MaxPlayers`, `Password` | название, режим из `modes/`, порт, слоты, пароль |
| `Admins` | SteamID админов через запятую |
| `SteamAuth`, `SteamApiKey` | проверка Steam-аккаунтов: `optional` / `required` / `off`. Ключ API выдают на [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey) |
| `RconPassword` | `/rcon login <пароль>` в чате делает игрока админом на сессию |
| `MaxHitDamage`, `MeleeRange`, `MaxHitsPerSecond`, `CheatKick` | античит |
| `Scripts` | скрипты из `scripts/`, которые работают в любом режиме (как filterscripts) |
| `Http` | разрешить режимам HTTP-запросы (вебхуки Discord и т. п.) |
| `Voice*` | голосовой чат: дальность, лимиты |
| `Zombies` | экспериментальные фрики ([`docs/zombies.md`](docs/zombies.md)) |
| `Master` | мастер-сервер, чтобы сервер появился во вкладке «Интернет» |
| `SpawnX/Y/Z/Yaw` | точка появления по умолчанию (единицы Unreal, 100 = 1 м) |

### Консоль сервера

`help`, `status`, `say <текст>`, `kick`, `ban <id|ник|SteamID|IP> [минуты] [причина]`, `unban`, `bans`, `admin <id|ник> [off]`, `hitstats`, `voice [on|off]`, `bot [N]` / `bots off`, `reload`, `mode <id>`, `time <часы>`, `weather <id|auto>`, `quit`. Остальные строки получает режим через событие `console`.

Режим перезагружается сам при сохранении `.lua`, `.ini` или `.json`, перезапускать сервер не нужно. Журнал пишется в `logs/server.log`. Данные режимов хранятся в `data/<режим>/`, баны и закреплённые ники — в `data/`.

### Мастер-сервер

`dgmp-server --master [--port 7700]` запускает список серверов для вкладки «Интернет». Как поднять свой мастер и указать его лаунчеру, описано в [`docs/master.md`](docs/master.ru.md).

## Режимы

Режим — это папка `modes/<id>/` с файлами `meta.ini` (название, описание, автор) и `main.lua`. Минимальный пример и весь API собраны в [`docs/API.md`](docs/API.ru.md).

Примеры, с которых удобно начинать:

| Режим | Что показывает |
|---|---|
| `freeroam` | основа: чат, команды, скины, телепорты, время и погода, админ-команды |
| `rp` | основа RP-сервера: аккаунты по Steam, деньги, магазин, больница, RP-чат, работы |
| `race` | гонки по чекпоинтам из редактора |
| `loader` | работа грузчиком: NPC, переноска ящиков, оплата |
| `htmlui` | HTML-интерфейс поверх игры |
| `clientdemo` | клиентские скрипты: HUD, клавиши, лучи из камеры |
| `inventory` | свой инвентарь с картинками |
| `zombies` | фрики и орды (`Zombies=1`) |
| `outpost` | Рубеж — RP-режим тестового сервера: профессии, экономика, места заданий со своим слоем, меню игрока (отряд, обмен, рация, медик, охрана, дуэли), ранение вместо смерти, обучение |

Общие библиотеки для режимов (`logic`, `quest`, `jobs`, `rpchat`, `inventory`, `race`, `interact` — меню игрока, `squad` — отряды, `trade` — обмен, `medic` — помощь раненым, `instance` — дуэли и арены) лежат в `modes/_lib/`.

Документация (у каждой страницы есть английская версия без `.ru`):

- [`docs/API.md`](docs/API.ru.md) — серверный Lua API: события, игроки, транспорт, NPC, объекты, HUD, хранилище, HTTP, баны, античит, `server.ini`.
- [`docs/client-lua.md`](docs/client-lua.ru.md) — клиентские скрипты (`modes/<id>/client/`).
- [`docs/webui.md`](docs/webui.ru.md) — как устроен HTML-интерфейс.
- [`docs/quests.md`](docs/quests.ru.md) — формат квестов и работ (`quests/<id>.json`).
- [`docs/items.md`](docs/items.ru.md) — ключи предметов и оружия.
- [`docs/looks.md`](docs/looks.ru.md) — облики персонажей.
- [`docs/zombies.md`](docs/zombies.md) — фрики в мультиплеере (прототип).
- [`docs/releases.md`](docs/releases.ru.md) — выпуск версии: GitHub Releases, `update.json` и обновление из лаунчера.

### Тестирование без игры

`build/dgmp-probe.exe` подключается к серверу как игрок и помогает проверить режим или сеть:

```bat
build\dgmp-probe.exe query 127.0.0.1:7777
build\dgmp-probe.exe lan
build\dgmp-probe.exe master 127.0.0.1
build\dgmp-probe.exe join 127.0.0.1 TestBot --seconds 30 --say "/help"
```

Кроме того, в консоли сервера команда `bot [N]` добавляет ботов.

## Редактор

Редактор открывается кнопкой «Редактор» в лаунчере или командой `DGMP.exe --editor`. Сначала выберите режим: у каждого режима свои правки мира, они хранятся в `modes/<режим>/world.json`, а сервер загружает их при старте режима. Квесты сохраняются в `quests/`, списки скинов — в `modes/<режим>/skins.json`.

| Клавиша | Действие |
|---|---|
| F2 | полёт вкл/выкл |
| WASD, Пробел / Ctrl | движение по камере, вверх / вниз |
| Shift, `[` / `]` | ускорение ×4, скорость полёта |
| F3 | дев-меню: время, погода, метки карты |
| F5 / F8 | сохранить точку старта / вернуться на неё |
| F6 | записать маркер в `maps/markers.jsonl` |

Координаты указываются в единицах Unreal: 100 единиц = 1 метр. Это те же координаты, что использует Lua API.

## Настройки клиента — `DGMP.ini`

Файл личный и в репозиторий не входит: при сборке из исходников скопируйте `DGMP.ini.example` в `DGMP.ini` (и `editor.ini.example` в `editor.ini`), пакет клиента кладёт свой. Мут и громкость игроков из списка Tab хранятся там же, в `[Players]`.

- `[DGMP]` — `AutoLoad`, `AutoFly`, `FlySpeed`, `SuppressStory` (отключить сюжетные задания), `SuppressAI` (убрать штатных NPC и фриков).
- `[World] RevealMap=1` — открыть всю карту без тумана.
- `[Map]` — какие штатные метки показывать на карте.
- `[Spawn]` — точка старта редактора (`Enabled=0` вернёт стандартную).
- `[Voice]` — микрофон, клавиши, громкость.

## Структура репозитория

```
src/              клиент (version.dll): хуки UE, сеть, HUD, редактор, голос, клиентский Lua
src/server/       выделенный сервер и мастер-сервер
src/launcher/     лаунчер (WebView2); его интерфейс — launcher/ui/
src/shared/       общий сетевой код клиента, лаунчера и probe
src/tools/        тестовый клиент dgmp-probe
api/              C-API DLL (dgmp.h) и пример
modes/            режимы; modes/_lib/ — общие Lua-библиотеки
scripts/          скрипты сервера для всех режимов
quests/           квесты и работы
data/             каталоги игры (облики, части, пропсы, анимации, звуки)
worlds/bootstrap/ общее стартовое сохранение и его manifest
docs/             документация
tools/            юниты systemd, сборка пакета и выпуск релиза, вспомогательные скрипты исследования
third_party/      Lua, ENet, Dear ImGui, ImGuizmo, WebView2 SDK
```

Не хранятся в git и создаются при работе: `build/`, `runtime/`, `profiles/`, `logs/`, `cache/`, `data/<режим>/`, собранные `.exe`, `DGMP.ini`, `editor.ini`.

## Диагностика

- `logs/DGMP.log` — клиент в игре.
- `logs/launcher.log` — лаунчер, подготовка `runtime/` и обновления.
- `logs/server.log` — сервер; при падении сюда же пишется стек вызовов.
- `telemetry.json` — состояние клиента и координаты, обновляется раз в секунду.

Если игра не запускается из лаунчера, проверьте, что работает Steam, Days Gone закрыт, а версия EXE поддерживается (см. «Требования»). `DGMP.exe --prepare-only` заново подготовит копию и профиль. Не удаляйте `runtime/` рекурсивно скриптами: внутри ссылки на файлы самой игры.

## Лицензия

DGMP распространяется под **GNU GPL 3.0** ([`LICENSE`](LICENSE)): код можно использовать, изменять и распространять, но изменённые версии DGMP (клиент, сервер, лаунчер, редактор) тоже должны выходить с исходным кодом под GPL 3.0.

**Режимы — ваши.** Режимы и скрипты для DGMP (Lua в `modes/<id>/`, `scripts/`, клиентские скрипты, HTML-интерфейс, `world.json`, квесты) только пользуются API сервера и клиента и не считаются производными от DGMP. Авторы режимов сами решают, как их распространять, в том числе закрыто. Примеры режимов и библиотеки в `modes/` из этого репозитория выходят под GPL 3.0 вместе с ним.

Сторонние компоненты идут под своими лицензиями (`third_party/`): ENet, Dear ImGui, ImGuizmo и Lua — MIT, Microsoft WebView2 SDK — лицензия Microsoft.
