# Общий стартовый шаблон

`world.sav` — точная копия предоставленного автором слота 2, сохранённого 14 октября 2026 в 01:49:58 (+07:00). Автор подтвердил стандартную сложность и персонажа без прокачки после пролога. Эти свойства ещё нужно проверить при загрузке в DGMP; бинарные записи сюжета вручную не редактировались.

`profile.sav` — сопутствующий профиль той же установки, взятый при подготовке шаблона. Он фиксирован для всех новых профилей DGMP и не импортируется заново из личных данных игроков. Файл может содержать настройки, глобальные счётчики и открытия из исходного профиля; его полная очистка ещё не выполнена. Состояние персонажа и мира берётся из общего игрового слота.

`manifest.json` фиксирует версию шаблона, поддерживаемый EXE, размеры, SHA-256 и происхождение. Идентификатор Steam автора и локальные пути в пакет не включены. Возможная привязка внутри бинарного формата не исследована; реальная загрузка на другом Steam-аккаунте ещё не проверялась.

При запуске `prepare.ps1` мир копируется в отдельный слот 1 текущего Steam-аккаунта, профиль — в его отдельную папку DGMP. Подавление штатных заданий, раскрытие карты и отключение гнёзд выполняет код мода после загрузки; эти изменения не записаны в исходный шаблон. Файлы шаблона нельзя перезаписывать игровым прогрессом режима.

Для обновления шаблона нужны новые согласованные файлы и новый manifest с их хешами. Ошибка проверки прерывает подготовку; автоматического перехода к личному сейву нет.
