## DGMP v0.5.2 — меню паузы

- Установлена причина, почему прежний поиск не находил кнопки сохранения: Type содержит EProfileOption::MenuOnly, а действие хранится в ProfileOption (EPlayerSaveProfileType). Enum у ByteProperty располагается по +0x78.
- По enum определяются Menu_SaveGame, Menu_LoadGame, Menu_PhotoMode и Menu_QuitToMainMenu. Локализация названий не влияет на фильтр.
- Записи ActiveMenuProfile удаляются вместе с соответствующими CategoryWidgets и кнопками в дереве интерфейса. MaxCategoryIndex и CursorPosition пересчитываются; исходные профили меню фильтруются для повторной инициализации.
- Удаление выполняет штатный GenericArray_Remove движка (RVA 0x2917F70), найденный по execArray_Remove. Он корректно уничтожает элементы структуры/FText; массивы не копируются вручную. Сигнатура и диапазон индексов проверяются перед вызовом.
- Для несовпадающей структуры меню предусмотрено скрытие и отключение. Обработчики загрузки, фоторежима и возврата в главное меню заблокированы в OptionsTopMenuWidget; штатный bootstrap LoadGame этим не затрагивается.
- MSVC x64: DLL и лаунчер собраны без предупреждений. Установлена сборка v0.5.2, проверка меню в игре продолжается. Оригинальные сохранения и DGCoop по SHA-256 не изменены.
- Игровая проверка v0.5.2: журнал `Pause menu filtered: remaining=3; removed=4`; ActiveMenuProfile содержит только настройки (ProfileOption 122), справку (55) и выход в систему (50). MaxCategoryIndex=3, исходный MenuProfiles уменьшен с 15 до 11, запрещённых четырёх типов в обоих списках нет. Диагностика: logs/pause-menu-after-v052.txt.
- Пользователь подтвердил: «Все четыре исчезли, выбор работает» — проверены мышь и клавиатура. Телеметрия после проверки: world-ready, errors=0.
